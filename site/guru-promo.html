🖼️ Image tools

Rebuilds every event photo as a 1200×630 Facebook-ready banner (full artwork on a blurred backdrop — never cropped). Safe to re-run: already-optimized photos are skipped, and nothing else about the events is touched (no conflict checks, no registrant emails). Facebook caches link images it has already scraped — to refresh an already-shared event, paste its link into Facebook's Sharing Debugger and hit "Scrape Again".

How the buttons work: Facebook won't let a website pre-fill a post, so each Facebook task copies the (editable) text above its button and opens facebook.com in a new tab — start a post, paste, tweak, share. The event links in the pasted text expand into preview cards on their own. The weekly task opens the public calendar with the share panel already open: hit the Facebook button there and it downloads the image and copies a caption — paste the caption and attach the downloaded PNG. Volume One tasks copy the full listing details and open two tabs (the event page and the VO submission form); if your browser blocks the second tab, use the extra buttons and allow pop-ups for gamehaven.guru. If Facebook's own dialog ever hangs on "Posting…", close it and paste into a normal new post instead. Every open happens in a new tab, so this list stays put and refreshes itself.
